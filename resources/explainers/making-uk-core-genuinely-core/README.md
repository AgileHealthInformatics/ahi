# Making UK Core Genuinely Core

Web explainer and full report adapted from Dr Tito Castillo’s October 2026 paper, Making UK Core Genuinely Core. Intended for NHS decision makers, clinicians, architects and standards specialists.

## Publication

Copy this directory to `/resources/explainers/making-uk-core-genuinely-core/` in the GitHub Pages website. The HTML is self-contained, with embedded branding, CSS and vanilla JavaScript. No build step or external dependencies are required.

Add a resource-library entry and a homepage new-content announcement with the title **Making UK Core Genuinely Core** and URL `/resources/explainers/making-uk-core-genuinely-core/`. Suggested description: “A shared register of health data meaning beneath UK Core: architecture, governance, delivery phases and the case for staged investment.”

## Features

Existing site header, embedded logo, root-relative navigation and footer; blue hero; persistent light and dark themes using `ahi-theme`; responsive report contents; present/proposed architecture comparison; filterable Move/Split/Stay classification; full source tables and linked references; print layout; keyboard controls and skip link. Main content remains readable without JavaScript.

## Evidence and editorial treatment

The paper remains the authority for dated descriptions of standards and governance. This is a proposed architecture, not an approved NHS programme. The report preserves the paper’s evidence limits, provisional catalogue mappings, lack of costs and absence of organisational commitments. The opening explainer clarifies that stable identifiers do not establish implementation equivalence. The nine content categories are not presented as a measured proportion of UK Core. No new clinical scenario or numerical evidence has been introduced.
