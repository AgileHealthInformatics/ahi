The design proposition

One meaning. Independent governance. Interoperable statistics.

A national reporting function can exchange statistics with other European statistical organisations using shared SDMX structures, while citing definitions controlled by a separate enterprise data dictionary. EHDS secondary-use services add a different concern: discovering actual health datasets through an HDAB catalogue.

The services below perform different jobs. SDMX is a practical choice for comparable, machine-readable statistical structures, automated checks and exchange across organisations; HealthDCAT-AP is the specified metadata framework for EHDS dataset descriptions under Commission Implementing Regulation (EU) 2026/2098, applying from 26 March 2029.

Three differences worth preserving

The distinction is about the kinds of things governed, not merely about which software product is deployed.

01 · Definition

What does a field mean?

A dictionary item records meaning and representation. An SDMX measure can cite that definition, but a statistical methodology is not reducible to a single source field.

02 · Measurement

How is a measure produced?

Statistical governance controls population rules, methodology, breakdowns, revisions and release processes. It owns the measure, not the clinical record from which it originates.

03 · Data asset

Which dataset actually exists?

An EHDS catalogue describes datasets held by real organisations and the conditions for requesting access. It is not a catalogue of indicator definitions alone.

Why choose SDMX rather than exchange spreadsheets?

Cross-organisation reporting creates repeatable structural and semantic problems. SDMX addresses important parts of those problems in a standardised way.

Common meaning

Reuse concepts and classifications

Data structures can reference governed concepts, dimensions and code lists. A recipient knows what each series represents, rather than interpreting ambiguous column headings.

Automated exchange

Validate against an agreed structure

Reporting teams can check expected dimensions, allowed codes and the identity of the dataflow before consuming observations. Mapping exceptions become visible.

Repeatable interoperability

Serve more than one partner

One approved statistical structure can support exchanges among national statistical authorities and European statistical organisations without negotiating a bespoke spreadsheet for each relationship.

Important boundary: SDMX standardises statistical structure and exchange; it does not establish clinical comparability, automatically harmonise different denominators, or grant EHDS access. Explore the interactive validation exercise to see why methodological assurance is still required.

Where does the EHDS fit?

The HDAB obligation is to support discoverability and governed secondary use. It does not prescribe SDMX as the metadata model for its dataset catalogue.

The required path

Health data holder → HDAB dataset catalogue → discovery and authorised secondary use. The HDAB makes standardised, machine-readable dataset descriptions available. HealthData@EU connects national catalogues and supports cross-border secondary-use arrangements.

EHDS Articles 60, 75, 77 and 79

The additional statistical interoperability path

Data dictionary → SDMX reporting registry → interoperable statistical exchange. Standard concepts, data structures, code lists and reference metadata can help different statistical organisations exchange and interpret published measures, with relevant outputs also linked to discoverable health datasets.

Source-level semantic authority

What exactly does SDMX contribute?

It creates a common technical contract for independently managed statistical collections. The surrounding governance still matters.

EHDS relationship: Standardised statistical outputs may inform secondary-use discovery and analysis, but an HDAB must still fulfil its dataset-catalogue and access responsibilities. HealthDCAT-AP describes actual datasets. An SDMX dataflow does not replace an EHDS catalogue record, data permit or secure processing arrangement.
EHDS secondary-use service

An HDAB catalogue describes datasets, not just indicators.

Health data holders describe real information assets. A Health Data Access Body (HDAB) makes the catalogue discoverable, manages access applications and connects into the wider secondary-use arrangements. The reporting registry can enrich descriptions, but does not replace the HDAB catalogue.

Critical separation: an indicator may describe how a result is calculated, whereas a dataset description tells an applicant what data exists and how access can be requested. The former can improve discovery, but the HDAB catalogue and access processes must still exist in their own right.

Dependency and release assessment

The service contract matters more than the product pairing.

01. Stable identifiers

Use persistent identifiers and immutable published versions to keep historical statistical results interpretable.

02. Change notifications

Emit dependency-relevant events or scheduled change feeds, with effective dates and material-change classifications.

03. Local autonomy

Reporting owners evaluate impact and approve new statistical releases. Dictionary stewards approve the source definitions.

The change-impact mechanism shown here is a proposed integration design. It is not an out-of-the-box guarantee of either a metadata registry product or the SDMX standard.
Operating model and standards

The boundaries make federation manageable.

The arrangement works when each service has a clear authority, an explicit interface and an agreed change process. It should not require every governance team to operate the same software platform.

Architectural conclusion

Govern data meanings where they originate; govern statistical methods where they are produced; publish dataset descriptions where access is coordinated. Connect these responsibilities through versioned semantic references and explicit service agreements. An SDMX registry can also underpin repeatable statistical exchange between European reporting organisations, reducing bespoke mappings and enabling structural validation. Methodological comparability still needs assurance; HealthDCAT-AP dataset publication and HDAB access governance remain separate EHDS concerns.
