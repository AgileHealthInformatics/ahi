# Healthcare Pathway Description Standard resource

This directory contains the public Agile Health Informatics Ltd introduction to the proposed Healthcare Pathway Description Standard (HPDS).

## Public path

`/resources/clinical-pathways/healthcare-pathway-description/`

The directory uses `index.html` so the public URL remains stable if the working draft changes version.

## Purpose

The page is a concise introduction to the proposal. It explains:

- why healthcare pathways are candidates for catalogue-based governance;
- the distinction between pathway definition, pathway implementation and pathway instance;
- the principal classes of information that a catalogue-ready pathway description can contain;
- how HPDS is intended to complement ISO 13940, HL7 FHIR, BPMN, CMMN, DMN and WHO SMART Guidelines rather than replace them;
- the four cumulative conformance levels in the working draft;
- the deliberate boundaries of the proposal; and
- the route to the frailty and multimorbidity demonstrator.

The page must continue to describe HPDS as a working proposal. It must not imply ISO, IEC or national standards-body approval.
