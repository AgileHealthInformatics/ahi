# Healthcare Standards Navigator

[Open the interactive navigator](index.html)

## About this resource

The **Healthcare Standards Navigator** is an interactive guide to selecting and combining health and care standards across interoperability, process, assurance, analytics and professional practice.

It is intended to make a complex standards landscape easier to navigate by starting with the problem and use case rather than with a catalogue of standards.

## What it helps you do

Use the navigator to:

- identify what kind of standard is needed;
- search standards by problem, domain or jurisdiction;
- distinguish health-specific standards from cross-sector foundations;
- build standards stacks around use cases;
- see how standards combine in practice;
- compare current use with future strategic relevance;
- identify common category errors; and
- review authoritative source material.

## How to use the navigator

### 1. Start with the problem

The page opens with **Start with the problem, not the standard**.

Use this as the guiding principle for the rest of the navigator.

### 2. Search and filter

The catalogue can be filtered using:

- **Search name, role or problem**;
- **Domain**;
- **Jurisdiction relevance**;
- **Landscape position**; and
- **Scope origin**.

Domains include analytics and research, data and interoperability, process and computable knowledge, professional standards, and security/privacy/clinical safety.

Jurisdictions include UK-wide, the four UK nations, Europe/EU, United States, Canada, Australia and New Zealand.

### 3. Use the use-case controls

The navigator includes selectors for:

- **Primary use case**;
- **Jurisdiction**;
- **Lifecycle stage**;
- whether clinical risk is material;
- whether AI is in scope; and
- whether regulated medical-device software may be in scope.

These inputs help identify a combination of standards rather than one isolated choice.

### 4. Build a standards stack

Use the stack-building section to see which standards play complementary roles.

Examples of covered areas include clinical APIs, shared care, semantic interoperability, medicines, pathology, imaging, cross-border summaries, metadata, analytics, research, clinical safety, security and medical-device concerns.

### 5. Compare current and future relevance

The navigator allows sorting by:

- current use;
- future relevance; and
- name.

The scoring is intended as a navigation aid, not an official adoption metric.

### 6. Review jurisdictional interpretation

The same standard may have different implementation status, profiles or policy significance in different jurisdictions.

The jurisdiction section should therefore be reviewed before applying a standards choice to a specific country or health system.

### 7. Use the source register

The source register points to the authoritative organisations and specifications used to construct the catalogue.

## PRSB context

The navigator treats PRSB standards as a **UK-wide reference set**, while recognising that adoption and implementation are not identical across the four UK nations.

## Limitations

This is a curated professional resource, not an official national standards catalogue, compliance register or certification service.

Current use and future relevance are interpretive indicators. Authoritative specifications and national implementation guidance remain the source of truth for conformance.

## Technical notes

The interactive HTML resource is self-contained and intended for static hosting. It uses standard HTML, embedded CSS and vanilla JavaScript, so no application server or build process is required.

When deployed in the Agile Health Informatics GitHub Pages site, keep this Markdown file in the same repository directory as its corresponding HTML file so the relative link above remains valid.
