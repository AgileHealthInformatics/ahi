# Metadata Management for a National Health Service

Web report for the **revised Version 1.0 candidate** of Dr Tito Castillo’s generic national metadata-management strategy.

## Publication

Publish this directory at:

`/resources/data-management/metadata-management-national-health-service/`

The page is self-contained HTML5 with embedded CSS, the Agile Health Informatics header and logo, root-relative navigation, light/dark theme support using `ahi-theme`, responsive layouts, print styling and vanilla JavaScript only.

## Source status

Source: **Metadata Management for a National Health Service**, Version 1.0 candidate, revised October 2026.

The web report preserves the candidate document’s distinction between firm strategy commitments and decisions left to the adopting organisation. It also preserves the scope boundary between nationally governed semantic/descriptive metadata and local technical or operational metadata.

## Revised candidate changes represented

The web version now reflects the revised candidate document, including:

- the revised publication status and wording;
- a UK example grounded directly in published UK Core, NHS Data Model and Dictionary and Core Information Standard sources;
- removal of the earlier self-citation and unpublished acute-trust catalogue citation from the evidence chain;
- renumbered references throughout, now ending at reference 15;
- the ten strategy principles, including explicit support for composite information requirements;
- the three-stage distinction between registered intent, implementation conformance and observed data quality;
- five operational metadata capabilities and the national metadata architecture;
- the national data dictionary treated as a governed national model of use;
- machine-actionable metadata suitable for software and AI-assisted tools without prescribing RDF or JSON-LD;
- operating indicators separated from measures of benefit;
- a scored pilot-selection matrix and formal phase 1 exit criteria;
- the revised glossary and readiness indicators.

Figures 1 to 3 are retained as accessible HTML/CSS diagrams. Tables 1 to 13 are rendered responsively from the revised source document.

## Evidence treatment

The resource presents the strategy as a proposal, not adopted national policy. Registration is described as recording intent and enabling assurance, not as proving implementation conformance or data quality. The revised evidence section relies on published sources for the UK examples.

## Placeholder and author conventions

The web version uses square brackets for any role or institution that an adopting country is expected to allocate to a named body or organisation.

This includes explicit institutional placeholders such as `[national health authority]` and `[national data standards board]`, and functional roles such as `[registration authority]`, `[registry operator]`, `[catalogue operator]`, `[governance forum]`, `[domain stewards]`, `[authoritative publisher]`, `[reference data publisher]`, `[national terminology release centre]`, `[specification publishers]`, `[approving body]` and `[commissioning bodies]`.

The brackets therefore indicate **local substitution or assignment**, not only national-level bodies.

Author credentials on the web page remain limited to **FBCS CITP**. References to CDMP and CHCIO remain removed.
