# Clinical Terminology and Semantics Navigator

[Open the interactive navigator](agile_health_informatics_clinical_terminology_semantics_navigator_2026.html)

## About this resource

The **Clinical Terminology and Semantics Navigator** is an interactive professional guide to the decisions needed to preserve meaning in health information.

Its central premise is that the difficult semantic decision is rarely simply *which code system should be used?* The more important question is what kind of meaning must be represented, exchanged, governed and preserved.

The resource therefore treats semantics as operational infrastructure rather than as a catalogue of vocabularies.

## What it helps you do

Use the navigator to:

- distinguish terminologies, classifications, code systems, value sets and mappings;
- identify the semantic purpose of a use case before selecting a standard;
- explore terminology and semantic resources by family and jurisdiction;
- understand the role of terminology services;
- examine mapping and mediation risks;
- identify common forms of semantic debt;
- consider governance and conformance; and
- review findings, evidence type and sources.

## How to use the navigator

### 1. Start with the semantic problem

Use **What semantic problem are you solving?** to orient the page around the purpose of the terminology or semantic decision.

### 2. Search and filter

The navigator provides controls for:

- **Search terminology, semantics or risks**;
- **Semantic family**;
- **Use context**; and
- **Jurisdiction relevance**.

Use these together when investigating a specific standard, mapping issue, medicines problem, laboratory terminology or semantic risk.

### 3. Work through the semantic layers

The navigator distinguishes several governed layers:

- concepts and definitions;
- code systems and classifications;
- value sets and bindings;
- mappings and mediation; and
- services, versions and preservation.

This helps prevent category errors such as treating a value set as though it were a terminology.

### 4. Review the decision guidance

The page includes six questions to consider before coding and a section on selecting terminology by semantic purpose.

### 5. Examine the semantic stack

Use the semantic-stack section to understand how terminology, value sets, mappings, services, metadata and conformance work together.

### 6. Review semantic debt

The navigator identifies recurring failure patterns including approximate mapping, ungoverned vocabulary choice, systemless coding, retrospective recoding, linguistic flattening, semantic monoculture, hidden mediation and premature information loss.

### 7. Use the findings register

The findings register can be searched and filtered by severity and evidence type.

Use it when you need a more explicit statement of the navigator's analytical conclusions.

## Main themes

- terminology is not classification;
- a code system is not a value set;
- version is part of meaning;
- clinical fidelity and statistical aggregation are different axes of value;
- terminology services make governance executable; and
- semantic governance benefits from federated expertise with coordinated publication.

## Limitations

This navigator is a professional decision aid. It does not replace the authoritative specification, licensing terms, implementation guidance or governance requirements of any terminology or coding system.

Jurisdictional applicability and adoption should be checked against current national guidance before a production implementation is designed.
