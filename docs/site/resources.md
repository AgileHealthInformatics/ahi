# Agile Health Informatics Resources

[Open the Resources page](../../resources.html)

## About this page

The **Resources** page is the public knowledge-base index for Agile Health Informatics Ltd.

It brings together navigators, comparative reference atlases, assessment tools, workshop guides and longer-form publications so that users can start with the type of question they need to answer.

## How to use the resource library

### Start with the question

The page groups resources around three broad needs:

- choosing standards, patterns and architecture components;
- comparing architectures and national environments; and
- turning architectural concepts into structured assessment.

### Search the collection

Use the search box to find resources by subject, standard or topic.

Examples include interoperability, terminology, architecture, operability, AI assurance and health data.

### Filter by resource type

The resource-type filter includes:

- Navigators;
- Reference atlases;
- Assessment tools; and
- Workshop guides.

Select **All resource types** to restore the complete collection.

## Interpretation

The resources are intended to support professional reasoning and decision-making.

Individual navigators and assessments have their own scope and limitations, which should be read before using them as evidence in a formal architecture, assurance or procurement decision.

## Contact

The final section provides a route for discussing how a resource might be applied to a real programme or architecture problem.

## Technical notes

The interactive HTML resource is self-contained and intended for static hosting. It uses standard HTML, embedded CSS and vanilla JavaScript, so no application server or build process is required.

When deployed in the Agile Health Informatics GitHub Pages site, keep this Markdown file in the same repository directory as its corresponding HTML file so the relative link above remains valid.
