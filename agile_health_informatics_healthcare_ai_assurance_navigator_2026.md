# Healthcare AI Assurance Navigator

[Open the interactive navigator](agile_health_informatics_healthcare_ai_assurance_navigator_2026.html)

## About this resource

The **Healthcare AI Assurance Navigator** is an interactive guide to governing, validating, deploying and monitoring artificial intelligence in health and care.

It treats healthcare AI assurance as a **lifecycle evidence problem**, not simply a question of model accuracy.

The navigator combines health-specific safety and evidence concerns with wider AI governance, security and regulatory considerations.

## What it helps you do

Use the navigator to:

- identify the intended use and impact of an AI system;
- examine data, model, safety, legal, security and operational assurance together;
- select assurance controls by risk and lifecycle stage;
- build an assurance stack around a use case;
- compare relevant regimes and standards;
- consider monitoring, drift, change and exit;
- assess organisational maturity; and
- review key findings and evidence.

## How to use the navigator

### 1. Define the AI use case

Use **What AI are you assuring?** to orient the resource around the actual clinical or operational use rather than AI in the abstract.

### 2. Search and filter assurance material

Controls include:

- **Search control, evidence or standard**; and
- **Assurance family**.

Search terms such as drift, DCB0160, bias or PCCP can be used to find specific assurance topics.

### 3. Work through the eight assurance layers

The navigator organises evidence across:

1. governance and accountability;
2. intended use and impact;
3. data assurance;
4. model evaluation;
5. clinical safety and human factors;
6. legal, regulatory and security;
7. evidence, transparency and adoption; and
8. monitoring, change and exit.

### 4. Use the approval questions

The page includes six questions to consider before approval.

These are useful as an assurance-gate prompt but are not a replacement for formal regulatory or clinical-safety processes.

### 5. Review jurisdictional context

The navigator includes material relevant to:

- European Union;
- UK / England;
- United States and Canada; and
- cross-sector foundations.

### 6. Assess maturity

Use the maturity section to consider whether the organisation can keep an AI-enabled service trustworthy after go-live.

### 7. Review the findings register

Findings can be searched and filtered by severity and evidence type.

## Interpretation

The navigator repeatedly distinguishes the AI model from the service in which it is used.

Validation at deployment should not be treated as the end of assurance. Data changes, workflow changes, model updates, drift, emerging hazards and exit arrangements remain part of the lifecycle.

This resource is not legal advice, a regulatory conformity assessment, a clinical-safety case or a substitute for the requirements of the relevant regulator or professional authority.

## Technical notes

The interactive HTML resource is self-contained and intended for static hosting. It uses standard HTML, embedded CSS and vanilla JavaScript, so no application server or build process is required.

When deployed in the Agile Health Informatics GitHub Pages site, keep this Markdown file in the same repository directory as its corresponding HTML file so the relative link above remains valid.
