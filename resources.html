Public knowledge base

Healthcare architecture resources designed to support real decisions.

The library brings together navigators, reference atlases, assessments, practical guides and working proposals. Each resource is intended to make a particular class of healthcare architecture, data or informatics decision easier to examine.

Find the right starting point

Start with the kind of question you are trying to answer.

The resources are deliberately separated by the judgement they support. A standards-selection problem is different from a national architecture comparison, an operability assessment or the definition of a reusable clinical pathway.

1

Choose standards and patterns

Use the navigator suite when the question concerns interoperability, information models, semantics, integration, data architecture or assurance.

2

Compare environments

Use reference atlases when the task is to compare national architectures, data flows or integration capabilities without collapsing important differences.

3

Assess a capability

Use assessment tools and workshop guides when the aim is to examine maturity, operability, governance or implementation readiness in a structured way.

4

Describe clinical pathways

Use the Healthcare Pathway Description Standard resource to explore how pathway knowledge could be maintained as a governed, catalogue-ready business artefact.
